# Security policy

If you believe you have found a security vulnerability in this SDK or in the
ClinikEHR API, please report it privately by email to
**support@clinikehr.com** with the subject line **Security**.

Please do not open a public issue for a vulnerability. Include what you found,
how to reproduce it, and the version you tested. We will acknowledge your report
and keep you informed as we work on it.

Never include a live API key or patient information in a report.
